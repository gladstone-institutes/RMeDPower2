Complete Tutorial

Step-by-step guide to using RMeDPower2

5-Step Workflow

RMeDPower2 follows a systematic 5-step workflow for power analysis:

1️⃣ Input Data

Read your experimental data as a data frame with proper column headers

2️⃣ Specify Parameters

Define design, model, and power parameters using JSON templates

3️⃣ Diagnose Data

Test model assumptions and identify outliers

4️⃣ Power Analysis

Run statistical power calculations

5️⃣ Parameter Estimation

Estimate and visualize parameters of interest

Step 1: Input Data

Your data should be structured with rows representing individual observations and columns representing variables that capture both the response and the experimental design hierarchy.

library(RMeDPower2)

# Load example data
data(RMeDPower_data1)

# Or read your own data
# data <- read.csv("your_data.csv", header = TRUE)

Data Structure Requirements

  • Rows: Individual observations/responses
  • Columns: Predictor variables and experimental design variables
  • Headers: Column names are essential for defining S4 objects
  • Factors: Categorical variables should be properly encoded

Step 2: Specify Design Parameters

RMeDesign Class

Define your experimental design using the RMeDesign S4 class:

# Create design object manually
design <- new("RMeDesign",
    response_column = "measurement",
    condition_column = "treatment", 
    experimental_columns = c("subject", "timepoint"),
    condition_is_categorical = TRUE,
    crossed_columns = NULL,
    outlier_alpha = 0.05
)

# Or read from JSON template
design <- readDesign("design_template.json")

Key Design Parameters

response_column

Column name containing your response variable

condition_column

Column name for your main predictor/treatment variable

experimental_columns

Vector of column names defining experimental hierarchy (order matters!)

crossed_columns

Subset of experimental_columns representing crossed factors

ProbabilityModel Class

# Normal distribution (default)
model <- new("ProbabilityModel",
    error_is_non_normal = FALSE,
    family_p = NULL
)

# Non-normal distributions
model_poisson <- new("ProbabilityModel",
    error_is_non_normal = TRUE,
    family_p = "poisson"
)

# Or read from JSON
model <- readProbabilityModel("prob_model.json")

PowerParams Class

# Define power analysis parameters
power_param <- new("PowerParams",
    target_columns = c("subject"),
    power_curve = 1,
    nsimn = 1000,
    levels = c(1),
    alpha = 0.05,
    effect_size = NULL
)

# Or read from JSON
power_param <- readPowerParams("power_param.json")

Step 3: Diagnose Data and Model

Test modeling assumptions, identify outliers, and validate your model:

# Diagnose data and model assumptions
diagnose_res <- diagnoseDataModel(data, design, model)

# Check diagnostic plots
plot(diagnose_res)

# Examine outlier detection results
print(diagnose_res$cooks_distance_experimental_column1)
print(diagnose_res$outlier_observations)

What the Diagnosis Includes

  • QQ plots: Test normality assumptions
  • Residual plots: Check model fit
  • Outlier detection: Identify problematic observations
  • Group-level outliers: Find problematic experimental units
  • Transformations: Suggest data transformations if needed

Iterative Process

You may need to repeat diagnosis after removing outliers or changing model assumptions:

# Update data and design based on diagnosis
data_updated <- diagnose_res$Data_updated
design_updated <- design
design_updated@response_column <- "response_logTransformed_noOutlier"

# Re-diagnose with updated data
diagnose_res2 <- diagnoseDataModel(data_updated, design_updated, model)

Step 4: Calculate Statistical Power

Perform power analysis to determine sample sizes needed:

# Calculate power
power_res <- calculatePower(data, design, model, power_param)

# View power results
print(power_res)
plot(power_res)

Power Analysis Options

Power Curves (power_curve = 1)

Test power across a range of sample sizes:

power_param@power_curve <- 1
power_param@target_columns <- c("subject")
power_param@levels <- c(1)  # Increase number of subjects

Single Power Calculation (power_curve = 0)

Calculate power for a specific sample size:

power_param@power_curve <- 0
power_param@max_size <- c(20)  # Test with 20 subjects

Multi-level Analysis

Test power for multiple experimental variables:

power_param@target_columns <- c("experiment", "subject")
power_param@levels <- c(1, 1)  # Increase both experiments and subjects

Step 5: Estimate Parameters

Estimate and visualize your parameters of interest:

# Estimate parameters of interest
estimate_res <- getEstimatesOfInterest(data, design, model)

# View model summary
print(estimate_res[[1]])

# Plot association
plot(estimate_res)

What You Get

  • Model Summary: Fixed and random effects estimates
  • Effect Sizes: Magnitude of your treatment effects
  • Confidence Intervals: Uncertainty around estimates
  • Visualizations: Plots showing associations

Advanced Topics

Simulation Parameters

levels Parameter

levels = 1: Increase number of experimental units (e.g., more subjects)
levels = 0: Increase samples per unit (e.g., more observations per subject)

ICC Values

When variance components cannot be estimated from your data:

# Provide ICC values manually
power_param@icc <- c(0.1, 0.05)  # ICC for each experimental level

Effect Size Specification

# Use known effect size
power_param@effect_size <- 0.5

# Or let the package estimate from your data
power_param@effect_size <- NULL

Common Use Cases

Cell Assays

Hierarchical design: experiment → plate → cell line → individual cells

Single-cell RNA-seq

Count data with negative binomial distribution and library size offsets

Behavioral Studies

Repeated measures: subject → timepoint with potential log transformation

Electrophysiology

Nested design: mouse → brain slice → recorded cell
