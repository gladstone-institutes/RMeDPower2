RMeDPower2

Statistical Power Analysis for Repeated Measures Experiments

Complete functionality to analyze data from hierarchical or crossed experimental designs, test modeling assumptions, identify outliers, estimate statistical power, and perform sample size calculations.

Get Started View on GitHub

Overview

RMeDPower2 is an R package designed for statistical power analysis in repeated measures experiments. It provides comprehensive tools for analyzing complex experimental designs commonly used in biomedical research.

🔬 Experimental Design Support

Handles nested and crossed experimental designs with multiple hierarchy levels

📊 Power Analysis

Simulation-based power calculations using advanced mixed-effects modeling

🎯 Outlier Detection

Two-level outlier identification at observation and group levels

✅ Model Validation

Comprehensive assumption testing and diagnostic visualizations

Installation

Install RMeDPower2 from GitHub using devtools:

# Install devtools if you haven't already
install.packages("devtools")

# Install RMeDPower2 from GitHub
devtools::install_github("gladstone-institutes/RMeDPower2", build_vignettes = TRUE)

Quick Start

Here's a basic example of how to use RMeDPower2 for power analysis:

library(RMeDPower2)

# Load example data
data(RMeDPower_data1)

# Perform power analysis
result <- calculatePower(
    data = RMeDPower_data1,
    condition_column = "treatment",
    experimental_columns = c("experiment", "plate", "well"),
    response_column = "response",
    condition_is_categorical = TRUE,
    effect_size = 0.5,
    nsimn = 100
)

# View results
summary(result)

Examples

Basic Power Analysis

Calculate statistical power for a simple repeated measures design:

# Basic power calculation
power_result <- calculatePower(
    data = your_data,
    condition_column = "treatment",
    experimental_columns = c("subject", "timepoint"),
    response_column = "measurement",
    condition_is_categorical = TRUE,
    effect_size = 0.3,
    nsimn = 1000
)

With Covariates

Include covariates in your power analysis:

# Power analysis with covariate
power_with_covariate <- calculatePower(
    data = your_data,
    condition_column = "treatment",
    experimental_columns = c("subject", "timepoint"),
    response_column = "measurement",
    covariate = "age",
    covariate_is_categorical = FALSE,
    include_interaction = TRUE,
    effect_size = 0.3,
    nsimn = 1000
)

Data Diagnostics

Test modeling assumptions and identify outliers:

# Diagnose data and model assumptions
diagnostic_result <- diagnoseDataModel(
    data = your_data,
    condition_column = "treatment",
    experimental_columns = c("subject", "timepoint"),
    response_column = "measurement",
    condition_is_categorical = TRUE
)

# View diagnostic plots
plot(diagnostic_result)

API Reference

Core Functions

  • calculatePower() - Main function for power analysis
  • diagnoseDataModel() - Test modeling assumptions and identify outliers
  • transform_data() - Handle data transformations and outlier removal
  • get_model_and_data() - Fit linear mixed effects models

S4 Classes

  • RMeDesign - Experimental design specification
  • ProbabilityModel - Error distribution assumptions
  • PowerParams - Power analysis parameters

Helper Functions

  • build_fixed_formula() - Construct fixed effects formulas
  • build_random_formula() - Construct random effects formulas
  • check_normality() - Validate normality assumptions
  • get_residuals() - Extract model residuals for diagnostics
